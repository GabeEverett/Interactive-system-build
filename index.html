COVID RIVER / v2

Self as System — one data-driven current. Remove one thing, add nothing, make what remains carry the work.

Rules

  1. Each region loads its data into a single river surface.
  2. Cumulative cases → saturation → color and choppiness (calm petrol → critical rust).
  3. Daily new cases → flow speed of the current.
  4. Your cursor pushes one swell across the surface.

Saturation bands — CALM <40% · TURBULENT 40–75% · CRITICAL >75% of the peak region.

Controls

  • Select a region in the bottom bar.
  • Move the cursor over the river to push a swell.
  • Toggle these notes.

Reflection on v1 (before building)

  • KEEP Data drives motion — new cases set the river’s flow speed. It was the one behavior that read without explanation.
  • REMOVE The HUD chrome — scanlines, cyber-grid, ambient glow, corner frames, neon badges, mesh toggle. The noisiest layer, and it faked the atmosphere the river should have earned.
  • TIGHTEN Saturation thresholds — vague in v1, now explicit calm / turbulent / critical bands that visibly change color and turbulence.
  • v2 Q Can data alone generate atmosphere once the decoration it was leaning on is gone?

v2 reflection (after building)

v1 was a pile of features wearing a sci-fi HUD, and the atmosphere was carried by decoration stacked on top of the canvas rather than by the system itself. For v2 I removed the entire chrome layer and added nothing: no new inputs, no new visual layers, no second river. The surviving rule — data drives motion — had to hold the whole piece up. Rebuilding it in Three.js as one continuous surface forced every quality to come from the water: saturation now sets both color and choppiness on explicit bands, and daily cases set the flow, so the mood of a region is legible in the current alone. The cursor is the only gesture left, a single swell that proves the surface is live without cluttering it. Removing the chrome improved the meaning because the piece can no longer hide behind atmosphere it did not produce. The finding: the HUD was not load-bearing — it was a crutch, and the river stands up better without it.

End-of-build reflection

  • What changed from v1: flat 2D canvas + HUD chrome became one 3D shader-driven river; the data mapping is the same idea, now the entire visual.
  • What became clearer: the saturation thresholds — with real bands, a calm region and a critical one are instantly distinguishable.
  • What I removed and why: the HUD chrome; it was noise faking atmosphere, and its removal makes the data legible as mood.
  • v3 risk: one controlled state shift — let a region cross a threshold mid-view and have the whole river phase-change, calm to unstable, in a single timed transition.
